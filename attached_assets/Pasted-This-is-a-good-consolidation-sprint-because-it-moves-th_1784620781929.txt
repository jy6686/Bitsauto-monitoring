The architecture

The Commercial Dashboard should always follow this pipeline:

Authenticated User
        ↓
Hierarchy Scope Service
        ↓
Visible Account IDs
        ↓
Commercial Dashboard APIs
        ↓
Dashboard Widgets

There should be no global queries on the Commercial Dashboard.

Every widget—cards, charts, tables, balances, live calls, reports, and BitsEye—must first resolve the user's hierarchy and then query only the accounts within that scope.

That makes the Commercial Dashboard fundamentally different from the NOC Dashboard, even if they share some visual components. The NOC Dashboard is network-centric, while the Commercial Dashboard is portfolio-centric. That distinction should drive both the data and the KPIs.
