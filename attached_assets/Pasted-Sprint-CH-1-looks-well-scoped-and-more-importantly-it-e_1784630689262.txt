The pattern I'd freeze

I would now make CH-1 the canonical implementation pattern.

Every Commercial module should follow exactly these phases:

Phase 1

Resolve scope.

getVisibleAccountIds()
Phase 2

Execute scoped SQL.

WHERE account_id IN (...)
Phase 3

Return commercial metadata.

For example:

{
  "scopeError": null,
  "orgRole": "Manager",
  "kamIds": [],
  "data": []
}
Phase 4

Render.

React should never compute hierarchy.

Before CH-2

I would make one small refinement.

Instead of every route calling:

getVisibleAccountIds(...)

consider a helper.

For example:

resolveCommercialScope(req)

which returns:

{
    accountIds,
    kamIds,
    orgRole,
    scopeError,
    isAdmin
}

Then every endpoint becomes:

const scope = await resolveCommercialScope(req);

const rows = await query(scope.accountIds);

That removes repeated boilerplate before CH-2 through CH-7.
