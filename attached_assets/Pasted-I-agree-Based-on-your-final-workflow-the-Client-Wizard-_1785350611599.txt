What should be removed

The following should be removed from the standard onboarding flow:

Client Wizard
Wizard Required badge
"Complete Client Wizard" message
Any wizardCompleted or wizardDraft checks that block provisioning

The Configuration page can remain in the system as an advanced configuration tool for administrators, but it should not be required to onboard a new customer.

This results in a much cleaner business process:

Create Company → Auto-create Tariff & Service Plan → Admin approves IP → Provision → Customer is ready for testing.
