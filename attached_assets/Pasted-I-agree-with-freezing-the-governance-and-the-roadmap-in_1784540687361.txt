F3 Implementation Principles

Since F3 is the first independent consumer of the Financial Snapshot, I would establish three implementation rules before any coding begins.

Rule 1 — Read-only consumer

F3 must never modify financial data.

financial_snapshot
        │
        ▼
Reconciliation
        ▼
Evidence

It should read from the snapshot and produce reconciliation results and evidence only. Corrections belong upstream (F1), not in F3.

Rule 2 — Explainability first

Every discrepancy should answer three questions:

What differed?
By how much?
Why?

For example:

Client	Revenue	Platform	Difference	Reason
ABC Telecom	1250.40	1249.80	0.60	Grace period adjustment

This makes reconciliation actionable rather than just a list of mismatches.

Rule 3 — Evidence is immutable

AI evidence should be tied to the snapshot that produced it.

Snapshot #182
      │
      ▼
Reconciliation #57
      │
      ▼
AI Scan #41

Even if a new snapshot is generated later, historical reconciliation and AI evidence should continue to reference the original snapshot used for analysis.

Exit condition for F3

Before certifying F3, I would require evidence that:

every reconciliation row references a snapshot_id;
every AI finding references both a snapshot_id and a reconciliation record (or underlying financial evidence);
no reconciliation logic reads directly from DMR or CDR data;
all reconciliation metrics map directly to entries in the Finance Data Dictionary, satisfying your new Single Source of Truth Rule.
Overall assessment

The project has now reached a point where the governance is supporting—not slowing—the implementation.

Your progression is coherent:

F1 establishes the canonical financial dataset.
F3 proves that dataset is internally consistent and explainable.
F2 publishes invoices from validated financial data.
Treasury consumes the same verified financial foundation.

That's the same architectural pattern used in mature carrier-grade billing systems: produce → validate → publish, with every metric traceable back to a single authoritative source.
