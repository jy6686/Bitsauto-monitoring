Failure 1: SPA navigation

resolveModuleComponent("clients")

returns null

registry entry missing
lazy import missing
lazy import failed
compiled bundle doesn't contain it

This is where a stale production bundle is a plausible explanation.

Failure 2: Hard refresh redirect

This one is more suspicious.

A stale JS bundle doesn't normally redirect to "/".

It usually gives:

blank page
NotFound
module not found
chunk load error

A redirect generally means React code intentionally navigated.

So I'd inspect:

PlatformAccessGuard
portal router
module resolver
default module selection
NotFound redirect logic

before assuming build artifacts.
