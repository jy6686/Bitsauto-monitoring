I like this model better because it mirrors how commercial organizations actually operate. I'd define the hierarchy like this:



Role	Own Accounts	Team Accounts	Other Teams	Write Access

CEO	✅	✅	✅	Full

VP Commercial	✅	✅ (all under VP)	❌	According to permissions

Commercial Manager	✅	✅ (direct team only)	❌	According to permissions

Team Lead	✅	✅ (assigned AEs only)	❌	According to permissions

Account Executive	✅	❌	❌	According to permissions

This Becomes a Platform-Wide Rule



Instead of implementing hierarchy separately for each module, every data query should respect a common access scope:



Portal

      ↓

Role

      ↓

Hierarchy Scope

      ↓

Data Filter

      ↓

Module



So whether the user opens:



Live Calls

BitsEye

Client Balance

Rate Manager

Reports

CDRs



the same hierarchy filter is automatically applied before any data is returned.



This gives you a single, consistent authorization model that every Commercial Portal module can rely on, making the platform easier to maintain and much harder to bypass.
