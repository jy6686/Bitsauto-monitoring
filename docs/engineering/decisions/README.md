# Architecture Decision Records (ADRs)

ADRs capture **why** a decision was made — distinct from the handbook (which
documents *what* the platform does). Each answers: Problem · Decision · Alternatives
· Consequences · Status (Accepted / Superseded / Deprecated).

Sourced primarily from `.agents/memory/` (institutional `[I]`) and cross-checked
against code. Where a decision conflicts with current code, the ADR points to the
open Verification Register entry.
