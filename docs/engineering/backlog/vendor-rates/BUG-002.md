# BUG-002 — Header-row detection heuristic

- **Objective:** correctly detect the header row even with merged/blank header cells.
- **Scope:** `parseFile()` header-row selection (`server/routes-vendor-rates.ts`).
- **Acceptance criteria (when picked up):**
  - Header row detected correctly for sheets where a data row has more filled cells
    than the (merged/blank) header row.
  - No regression on well-formed sheets.
- **Dependencies:** BUG-001 fix in place (found via its test).
- **Status:** **OPEN — deferred.** Current heuristic = "row with most populated
  cells." Replace with a scoring system later; **not now** (owner decision).
- **Owner:** Commercial.
- **Verification:** reproduced in unit test; no fix yet.
- **Related Bug(s):** BUG-001.
