# BUG-003 — Worksheet selection end-to-end

- **Objective:** the sheet the user selects is the sheet that gets imported into the DB.
- **Scope:** Preview → mapping → import flow (`VendorSheetUploader.tsx`,
  `routes-vendor-rates.ts` preview/import).
- **Acceptance criteria (verify on current deploy):**
  ```
  Workbook → user selects Pricing → Preview = Pricing → Mapping = Pricing
           → Import = Pricing → DB rows = Pricing
  ```
  Confirm imported `vendor_rate_sheet_rows` match the **selected** worksheet, not
  the first sheet.
- **Dependencies:** current code must be deployed (rule out deploy lag).
- **Status:** **OPEN — needs runtime reproduction.** Code trace shows `sheetIndex`
  is honoured end-to-end; symptom not reproducible from code alone. Do not close
  until DB rows verified.
- **Owner:** Commercial.
- **Verification:** `[V]` code path traced; ☐ runtime (upload T&C/Pricing workbook,
  pick Pricing, confirm DB rows).
